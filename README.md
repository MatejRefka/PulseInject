## PulseInject

PulseInject is a lightweight dependency injection container built around a resolution engine.

## Features

- Registration of concrete types
- Registration of concrete types against interfaces or abstract types
- Registration of existing instances
- Registration of existing instances against interfaces or abstract types
- Registration of value types and strings
- Configurable dependency lifetimes
- Circular dependency detection

## Installation
PulseInject is available as a prerelease package from [NuGet.org](https://www.nuget.org/packages/PulseInject)

```bash
dotnet add package PulseInject --version 0.1.0-beta.1
```

> **Beta:** PulseInject is under active development and its public API may change before version 1.0.
